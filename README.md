# WeebSense 🎌

**WeebSense** is a full-stack anime recommendation system that suggests anime based on content similarity using genres, descriptions, and user preferences.

## Features
- Content-based anime recommendations
- Real-time search
- Clean and modern UI
- Built with React, Node.js, and Express

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Recommendation: TF-IDF + Cosine Similarity
